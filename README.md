# Amara Oriaku — Portfolio

Personal portfolio site showcasing MIS & data science projects.

Live at: https://amara-lin.github.io

## Structure
- `index.html` — the whole site (HTML/CSS/JS in one file, no build step needed)
- `resume.pdf` — add your resume PDF here, same folder, this exact filename

## Editing
Everything you need to change is plain text inside `index.html`:
- Your name, tagline, and about text near the top
- The three `project-card` blocks — swap in your real projects
- Contact links at the bottom (email, LinkedIn, GitHub)

No build tools, no npm install — just edit and push.
